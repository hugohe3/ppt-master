## Suggest a tutorial

This list is curated from community recommendations. To suggest a resource or report a broken link, comment on [issue #225](https://github.com/hugohe3/ppt-master/issues/225), which remains open for additions. Please include:

- **Title and link**
- **Format and language** (video, written guide, and so on)
- **Topics covered** and who the resource is for
- **PPT Master version or date tested**, if known
- **A short note** on what makes it useful

Resources should focus on using PPT Master, be accessible to readers, and clearly identify their language and any relevant version or setup requirements.
