# Rule Owners

> Registry of every rule that more than one runtime file needs. Each rule has exactly one owner section, stated in full there; every other file in the "pointer only" column carries a one-line pointer to that section and no paraphrase. When a report-driven fix touches one of these rules, edit the owner, not the file where the report was noticed. When a new cross-file rule appears, add a row before writing the rule a second time. [`prompt-layers.md`](prompt-layers.md) §2 owns the one-owner principle; this file is its index.
