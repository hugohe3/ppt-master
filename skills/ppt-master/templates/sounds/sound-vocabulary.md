# Sound Cue Vocabulary

Complete post-motion map of the 186 bundled CC0 sound cues. Read this file
only after a concrete auditory cue job exists for a resolved transition or
object-animation row; then select one exact namespaced id and materialize it
with `sound_sync.py`.

**Reference — not a constraint**: sections expose each cue's primary catalog
context, while the final column preserves every registered context.
Labels, durations, and contexts are objective identity facts, not rankings,
recommendations, coverage targets, or automatic choices. Silence remains valid.
